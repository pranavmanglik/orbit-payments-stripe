# Stripe adapter architecture decisions

Architecture Decision Records (ADRs) document durable changes to the Stripe adapter's public
contract, lifecycle, security model, dependencies, and provider behavior. The architecture guide
describes the current adapter; an ADR records why a material choice was made and what alternatives
were considered.

No standalone ADRs have been recorded for this package yet. Add an ADR before merging a material
contract, security, dependency, or lifecycle change. Use the [ADR template](template.md).
